## 🧩 开源版图 · Ecosystem & Repositories

### 1. 本地优先知识工作台 · TopMind Workspace
- **[`topmind`](https://github.com/topmindspace/topmind)** — 本地优先的个人动态流与 AI 知识桌面工作台（*Personal Stream & AI Knowledge Desktop*）：随手记录，AI 自动整理建议、待办与记忆，确认后再写入本地 Markdown（[Homebrew Tap](https://github.com/topmindspace/homebrew-tap)）。
- **[`topmind-obsidian`](https://github.com/topmindspace/topmind-obsidian)** — Obsidian 桌面端 Topmind Stream 插件，集成流式笔记、AI 建议及写作交付工作流。
- **[`topmind-skills`](https://github.com/topmindspace/topmind-skills)** — 面向个人知识工作流的 Agent 技能集（捕获、整理、维护、记忆、账本与微信读书同步） · [`@topmindspace/topmind-skills`](https://www.npmjs.com/package/@topmindspace/topmind-skills)。

### 2. 通用智能体技能 · Agent Skills *(Claude Code · Cursor · Codex · OpenCode)*
- **[`topmind-writing-skills`](https://github.com/topmindspace/topmind-writing-skills)** — 8 个社交媒体内容创作技能：覆盖 X 短帖/长文、公众号文章、写作简报、去 AI 味改稿、排版、封面与长图 · [`@topmindspace/topmind-writing-skills`](https://www.npmjs.com/package/@topmindspace/topmind-writing-skills)。
- **[`topmind-presentation`](https://github.com/topmindspace/topmind-presentation)** — 同一份内容模型同时生成可翻页单文件 HTML 演示稿与可编辑 16:9 PPTX，支持现有 PPT 版式重构 · [风格画廊与演示](https://topmindspace.github.io/presentation/)。
- **[`topmind-research`](https://github.com/topmindspace/topmind-research)** — 双模式 AI 行业研究技能：按信源采集聚合成简报（`collect`），或对论文/报告做带溯源深度对比分析（`analyze`） · [`@topmindspace/topmind-research`](https://www.npmjs.com/package/@topmindspace/topmind-research)。
- **[`topmind-handoff`](https://github.com/topmindspace/topmind-handoff)** — 基于个人私有 Git 仓库的跨工具 AI 记忆与任务交接方案（*Cross-tool AI memory & task handoff*） · [`@topmindspace/topmind-handoff`](https://www.npmjs.com/package/@topmindspace/topmind-handoff)。

### 3. DeepSeek Harness (DSH) 插件 · DSH Plugins
- **[`dsh-super-kanban`](https://github.com/topmindspace/dsh-super-kanban)** — DSH 智能任务指挥台：从多条会话提炼任务卡，跟踪进展、阻塞与交付物验收，支持全局、右侧与悬浮三形态及流式快聊 · [项目主页](https://topmindspace.github.io/dsh-super-kanban/) · `dsh-super-kanban`。
- **[`dsh-super-mind`](https://github.com/topmindspace/dsh-super-mind)** — DSH 本地优先内容与 X 创作工作室：统一索引多来源素材，支持 6 状态流转、5 种视图、DSH 模型 10 种风格改稿与 CLI 接口 · [项目主页](https://topmindspace.github.io/dsh-super-mind/) · `dsh-super-mind`。

### 4. 交互实验与开源工具 · Experiments & Open Utilities
- **[`awesome-ai-recreations`](https://github.com/topmindspace/awesome-ai-recreations)** — 9 台可拖可拆的离线 3D 机械复刻互动页，含完整源码及可供 Agent 跟做的复刻流程 · [在线体验](https://topmindspace.github.io/awesome-ai-recreations/)。
- **[`x-pulse-bot`](https://github.com/topmindspace/x-pulse-bot)** — 双模式 X Pulse (Grok Bot) 交互画布模板（7 天个人 X 动态表盘回放 & 24 小时公共话题热度）。
- **[`topstream`](https://github.com/topmindspace/topstream)** — 个人 AI 探索、研究笔记与开源精选资源流。
