## 🧩 Ecosystem & Selected Repositories

### 1. Local-First Knowledge Workspace (`topmind`)
- **[`topmind`](https://github.com/topmindspace/topmind)** — Local-first personal stream & AI knowledge desktop workspace: capture thoughts freely, review AI suggestions/todos/memory, and approve before writing to local Markdown ([Homebrew Tap](https://github.com/topmindspace/homebrew-tap)).
- **[`topmind-obsidian`](https://github.com/topmindspace/topmind-obsidian)** — Topmind Stream plugin for Obsidian desktop with bundled writing & formatting delivery.
- **[`topmind-skills`](https://github.com/topmindspace/topmind-skills)** — Agent skills for capture, organization, memory, ledger, WeRead sync & writing (`@topmindspace/topmind-skills`).

### 2. Agent Skills (Claude Code · Cursor · Codex · OpenCode)
- **[`topmind-writing-skills`](https://github.com/topmindspace/topmind-writing-skills)** — 8 skills for human-sounding social writing: X posts/articles, WeChat posts, briefs, rewrites, formatting, covers & posters (`@topmindspace/topmind-writing-skills`).
- **[`topmind-presentation`](https://github.com/topmindspace/topmind-presentation)** — Turn materials into interactive single-file HTML decks and matching editable 16:9 PPTX files ([Live Gallery](https://topmindspace.github.io/presentation/)).
- **[`topmind-research`](https://github.com/topmindspace/topmind-research)** — Dual-mode AI industry intelligence (`collect`) and cited deep analysis (`analyze`) (`@topmindspace/topmind-research`).
- **[`topmind-handoff`](https://github.com/topmindspace/topmind-handoff)** — Cross-tool AI memory & task handoff backed by your own private git repo (`@topmindspace/topmind-handoff`).

### 3. DeepSeek Harness (DSH) Plugins
- **[`dsh-super-kanban`](https://github.com/topmindspace/dsh-super-kanban)** — AI task & project command board derived from DSH sessions with acceptance review and full-page/sidebar/floating views ([Website](https://topmindspace.github.io/dsh-super-kanban/) · `dsh-super-kanban`).
- **[`dsh-super-mind`](https://github.com/topmindspace/dsh-super-mind)** — Local-first content studio & 10-style AI rewriter for DSH and X creators ([Website](https://topmindspace.github.io/dsh-super-mind/) · `dsh-super-mind`).

### 4. Interactive Experiments & Stream
- **[`awesome-ai-recreations`](https://github.com/topmindspace/awesome-ai-recreations)** — 9 offline 3D interactive mechanical recreations with full source code and agent reproduction workflows ([Live Demos](https://topmindspace.github.io/awesome-ai-recreations/)).
- **[`x-pulse-bot`](https://github.com/topmindspace/x-pulse-bot)** — Dual-mode X Pulse (Grok Bot) interactive canvas & data pipeline.
- **[`topstream`](https://github.com/topmindspace/topstream)** — Curated AI research, technical explorations, and open-source resources.
